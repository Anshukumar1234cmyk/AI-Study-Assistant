# AI Study Assistant

## Project Overview
AI Study Assistant is a web-based application that helps students understand their study questions using Artificial Intelligence.

## Features
- Enter any study-related question.
- Generate AI-based answers.
- Simple and user-friendly interface.
- Powered by Google Gemini AI.
- Built using Streamlit and Python.

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python -m streamlit run app.py
```

## API Key Setup
Enter your Google Gemini API key in the application sidebar.

**Important:** Keep your API key private. Never upload it to GitHub.

## Project Purpose
This project is developed to help students get quick answers and support their learning with AI.
